# Переезд на постоянную базу (Supabase) без потери данных

Бесплатная база Render удаляется через 30 дней вместе со всей перепиской и памятью. Supabase бесплатен и не удаляет данные
(проект «засыпает» после недели без активности, но пока сервер Polaris работает и пингуется, этого не происходит).

Порядок важен: **сначала копия, потом смена базы.**

1. **Задеплойте эту версию** на Render (в ней есть резервная копия).
2. **Скачайте копию со старой базы.** Откройте Polaris в браузере → ⚙ → Настройки → внизу **«Резервная копия» → «Скачать копию»**.
   Файл `polaris-backup-ГГГГ-ММ-ДД.json` сохраните — это вся ваша переписка, фото, память, заметки, задачи и настройки.
3. **Создайте проект в Supabase** (supabase.com → New project, регион ближе к Render — Frankfurt). Запомните пароль базы.
4. **Возьмите строку подключения:** Project Settings → Database → Connection string → **Session pooler** (порт 5432).
   Подставьте свой пароль вместо `[YOUR-PASSWORD]`.
5. **Render → сервис `polaris-pl` → Environment:** замените значение `DATABASE_URL` на эту строку и сохраните. Сервис перезапустится,
   схема создастся сама (`AUTO_MIGRATE=true`).
6. **Войдите** в Polaris (пароль прежний — `POLARIS_PASSWORD_HASH` не менялся). База пока пустая.
7. **Восстановите данные:** Настройки → Резервная копия → **«Восстановить из файла»** → выберите сохранённый файл → подтвердите замену.
8. **Подключите заново** (в копию они не входят — это секреты, привязанные к серверу): ChatGPT (Настройки → Провайдер) и push-уведомления
   (Настройки → Уведомления).
9. Старую базу `polaris-db` на Render можно удалить, когда убедитесь, что всё на месте.

Файлы, созданные агентом (`file_write`), лежат на диске Render и пропадают при перезапуске. Чтобы они сохранялись, задайте в Environment
`SUPABASE_URL` и `SUPABASE_SERVICE_KEY` (Settings → API → `service_role`) — бакет `polaris-files` сервер создаст сам.
Переписка и фото хранятся в базе и этой настройки не требуют.
